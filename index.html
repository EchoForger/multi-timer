安装 MultiTimer

两种安装方式。
选你顺手的。

01 推荐

下载 DMG

打开安装包，将 MultiTimer 拖入“应用程序”文件夹。

下载最新版 ↓ macOS Ventura 或更高版本
02 Homebrew

用终端安装

两行命令完成安装，以后也可以通过 Homebrew 直接更新。

Terminal 
$ brew tap EchoForger/tap
$ brew install --cask multi-timer

首次打开若被 macOS 拦截，请右键 MultiTimer 并选择“打开”。应用启动后会通过 GitHub Release 检查更新，发现新版时由你确认是否安装；也可通过面板底部的“检查更新”手动检查。
